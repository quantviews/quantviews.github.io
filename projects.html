Статистика внешней торговли (МГИМО)

Актуальная статистика внешней торговли в одном месте. Данные приходят из разных источников, живут в разных классификациях и постоянно пересматриваются задним числом - собрать из них сопоставимый ряд вручную стоит дороже, чем проанализировать.

Проект сводит источники в единую модель, ведёт учёт пересмотров, считает индексы физических объёмов и отдаёт результат аналитикам: витринами для тех, кто работает мышкой, и API для тех, кто работает кодом.

github.com/quantviews/mgimo-foreign-trade · Работает · Python, DuckDB, Superset
